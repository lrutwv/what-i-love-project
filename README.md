#  My Little Corner 

A small personal website created as a beginner HTML & CSS project.

##  About the Project

"My Little Corner" is a personal website where I collected some of the things I like — including art, films, anime, books, cameras, random discoveries, and other little things.

I wanted the website to feel like a small personal corner of the internet, with a nostalgic/Y2K-inspired style.

##  Pages

- **Home** — The main welcome page and navigation to different parts of the website.
- **About** — A little about me and some of my interests.
- **Gallery** — A collection of anime, films, things I've made, and random finds.
- **Guestbook** — A small guestbook-style page with a message form and voicemail section.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS animations
- Flexbox
- CSS Grid

##  CSS Features

Some of the CSS features I practiced in this project include:

- Flexbox
- CSS Grid
- Positioning and z-index
- Hover effects
- Transitions and transforms
- `@keyframes` animations
- Responsive design
- Background images
- Borders and border images
- Form styling
- Pseudo-classes

##  Design

I wanted the website to have a nostalgic internet/Y2K-inspired feeling, using:

- Pixel-style typography
- Decorative images
- Animated elements
- Scrapbook-like borders
- Old internet-inspired graphics
- Soft colours and patterns
